# Blazor Order & Delivery System

## Project Objectives:
The objective of this project is to develop a comprehensive order and delivery system that streamlines the process for customers, delivery workers, and merchants. The system will allow customers to place food orders, pay online, and track deliveries. Merchants will manage orders and deliveries, while delivery workers will view available orders, manage deliveries, and calculate their commissions. 

## Audience:
1.	Customers: Users who will browse menus, place food orders, and track their deliveries.
2.	Delivery Workers: Individuals responsible for delivering orders to customers. They will be able to view available delivery orders, accept or auto-assign orders, and calculate their commissions.
3.	Merchants: Restaurant owners or staff who will manage customer orders, approve payments, track delivery status, and communicate with both customers and delivery workers.
4.	Admin: Admin who will view users account, and manage workers and merchants account.

## Tech Stack:
- **Frontend:** HTML, CSS, C#, Blazor.
- **Backend:** C#, ASP.NET Core，Azure Blob Storage.
- **Database:** SQL server / SQLite
- **Other tools:** Google Maps API, SignalR, Trello, GitHub, Figma
